# AI 任务导航

从真实任务出发，帮助不熟悉 AI 工具的人选择并使用合适的方法、skill、插件和外部服务。推荐附信息源，并区分文档支持、当前可用与实际验证。

## 使用场景

- 想做一个项目，但不知道 AI 能帮哪些步骤。
- 不清楚是否需要安装 skill、MCP、插件或使用外部 AI 服务。
- 希望发现有用的新方法，同时避免为了追热点增加不必要的工具。

## 工作流程

理解任务与进度 → 核实 Agent 能力 → 拆解难点 → 检索与核实方法 → 给出主路径、可选试验和下一步。

每个外部推荐提供来源、适用条件与验证状态。简单任务按需要缩短流程。没有联网能力时明确标记信息限制。

## 安装

将本仓库放到宿主的 skill 目录，确保 `ai-task-navigator/SKILL.md` 位于可发现的位置。

Codex 常见用户目录为 `~/.codex/skills/ai-task-navigator`；设置了 `CODEX_HOME` 时使用该目录下的 `skills/ai-task-navigator`。私有仓库下载或克隆需要账号访问权限。

其他支持 `SKILL.md` 的 Agent 按其加载方式使用；工具、联网和文件权限由宿主提供，本 skill 不自动安装依赖。

## 使用示例

```text
请用 $ai-task-navigator 分析：我想做一个支持多人搜索和订阅的招聘信息聚合器。
结合我当前的工具环境，给出每一步可以使用的 AI 方法和工具，并附对应信息源。
```

也可以在尚未安装时，让 Agent 读取本仓库的 `SKILL.md` 并按其流程完成任务。

## 文件

- `SKILL.md`：入口与导航流程。
- `references/source-guide.md`：检索来源与推荐规范。
- `agents/openai.yaml`：Codex 展示信息与默认调用提示。
